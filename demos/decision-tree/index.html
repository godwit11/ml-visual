决策树：一层一层把数据切干净

决策树做的事很朴素：在每个节点上挑一个特征和一道门槛，把样本分成两堆， 让两堆各自"更纯"一点，然后递归下去。这一页让你看着它一步一步长出来。

                1. 为什么决策树能分开"异或"，而线性回归、Logistic 都做不到？
                

                  异或的正负样本在对角线上，任何一条直线都切不开。
                  决策树是一连串轴平行的切分：先按 x₁ 切一刀，再在两边各按 x₂ 切一刀，
                  四块区域各自归一类。它靠"分段的方块"逼近任意形状，代价是边界全是横平竖直的台阶。
                

              

              

                2. 训练集准确率 100% 是好事吗？
                

                  通常是坏事。树长到能记住每个样本时，叶子会碎到只包住一两个点，
                  这些细碎的规则多半是在拟合噪声，换个数据集就失效。
                  判断标准要看没参与训练的样本——这也是为什么后面要讲交叉验证。
                

              

              

                3. 为什么切分只能"轴平行"，不能斜着切？
                

                  经典 CART 每次只用一个特征和一个门槛，条件形如
                  ，在二维平面上就是一条垂直于坐标轴的直线。
                  这让树极好解释（"花瓣宽 ≤ 0.8 就是 setosa"），
                  但也让它在对角边界上要堆很多台阶。想斜着切，就得用线性组合切分（ oblique tree），可解释性会打折。
                

              

              

                4. 同一份数据，Gini 和熵切出来的树会一样吗？
                

                  大多数时候一样，偶尔不同。两者都是"越纯越小"的凹函数，排序高度一致；
                  但在几个候选切分的不纯度下降非常接近时，可能选出不同的那刀。
                  这一页的实现已经和 sklearn 逐节点对拍过：增益值一致，只是遇到完全打平的候选时选择可能不同。
